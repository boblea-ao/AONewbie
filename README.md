# AONewbie - Quick Start

AONewbie is a transparent, always-on-top overlay that sits on top of Anarchy Online. It gives you a
fast item search, a nano list browser, a character config, a guide browser, boss/event countdown
timers, a real-time damage meter, live inventory/bank tracking, trade-list posting, scrolling combat text/icon ready cooldowns and many more - all without
alt-tabbing out of the game.

## The Launcher

The Launcher is a small app whose only job is to keep
AONewbie itself installed and up to date.

- **Install AONewbie** - first run, click the button in the bottom-right corner.
- **Update available** - a newer version is out; click the button to download and apply it.
- **Launch** - AONewbie is up to date; click to start the game overlay (the Launcher window
  closes once it does).
- If AONewbie's files ever go missing or get corrupted, clicking Launch repairs them
  automatically before starting - no need to reinstall by hand.
- The gear icon (top-right) shows where AONewbie is installed and which version you have.

## Using the overlay in-game

- **Anchor bar**: hover your mouse near the top of the screen to reveal the menu bar. Click an
  icon, or use its keybind, to open that tool.
- **Item search**: double-tap Shift to open it from anywhere, even while AO has focus. Type
  part of a name - word order doesn't matter (e.g. "jester reani" finds "Cloak of the Reanimated
  Jester").
- **Nano list**: browse nanos by profession, or check what you already have uploaded.
- **Guides**: look up quest and tradeskill guides without leaving the game.
- **Character config**: Implant/Symb designer / Perk planner / IP planner / Weapons & Clothing equip config.
- **Tools**: general tools like Whatbuffs / Weapon dps / Trickle / Macros.
- **Timers**: track boss/event countdowns.
- **Pocket bosses/boss locations & drops**: searching for a symbiant gives you details about PB drop location and loot.
- **Scrolling combat text / Icon ready cooldown / Duration tracker**: improves the UI with combat info.
- **Damage meter**: reads your AO client's own chat log in real time - no memory reading, no
  injection. Make sure combat messages are enabled in your AO chat settings.
- **Trade lists**: build a WTS/WTB list from your own items and post it to chat in one click. Also live notifications when something from your lists is posted  by a player.
- **Live inventory/bank tracking**: opt-in, Windows-only - see what you're carrying and what's in
  your bank right from the overlay.
- Panels can be dragged and resized; the overlay remembers where you left them.
- Right-click the tray icon (bottom-right of your taskbar) for About/Settings, or to fully exit
  the overlay.
